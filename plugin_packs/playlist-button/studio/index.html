Playlist Button

Ein Taster am Rahmen wählt die Playlist: kurz drücken öffnet das Menü und springt weiter, lang drücken startet die markierte Playlist. Jede Änderung hier wird sofort gespeichert.

„Menü zeigen“ wirkt wie ein kurzer Tastendruck. So siehst du Farbe und Größe auch ohne Taster.

Taster

Nimm einen Pin, den kein anderes Plugin und kein anderes Gerät benutzt. Der Taster verbindet den Pin mit GND.

Playlisten im Menü

Je länger die Ordnerliste gemerkt wird, desto schneller öffnet das Menü. Neue Ordner erscheinen dann erst nach dieser Zeit.

Aussehen

0 % ist unsichtbar, 100 % ist deckend. Bei etwa 50 bis 70 % scheint das Foto leicht durch.

Erweitert

Das Plugin legt dieses Overlay selbst an. Die Position des Menüs kannst du in der Weboberfläche unter Overlays verschieben; sie bleibt erhalten.
